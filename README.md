# K&E — releases

Windows installers for **K&E** (kitchen & event management).

- **Install:** download `KE-Setup-<version>.exe` from the newest release and run it.
  Windows may show "Windows protected your PC" (the installer isn't code-signed yet) — choose **More info → Run anyway**.
- **Updates:** installed copies of K&E check this page automatically and offer to restart when a new version is ready
  (or use the tray icon → **Check for updates**). Your data stays on your PC and is backed up before every update.

This repository only holds release installers.
